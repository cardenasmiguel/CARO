# Security Policy

If you find a security issue in caro5m, please report it privately.

**Do not open a public GitHub issue or pull request** for vulnerabilities (for example anything involving keys, order placement, or a way to interfere with another user's bot).

## Contact

Email: **cardenasmiguel@gmail.com**

You can also use [GitHub Security Advisories](https://github.com/cardenasmiguel/CARO/security/advisories/new) on this repository.

Please include the caro5m version (it appears in the log), your operating system, and enough detail to reproduce the issue. **Never send your `.env`, private key, or CLOB API credentials.**

We will try to acknowledge the report and, when a fix is ready, credit you if you want that.
